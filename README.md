# 实验性人物海报 · Editorial Portrait Poster

用于 Codex 的实验性编辑人物海报技能：**人物是绝对主体，排版强势介入**。巨大人物特写、超大文字与资料碎片互相裁切、压叠、打断，以局部印刷质感形成先锋杂志、街头拼贴和地下 zine 气质。

支持任何运动的运动员、赛车手、音乐人、演员、普通人物和虚构角色。可以只给名字、人物照片，或分别提供身份与风格参考。足球不是限制，也不会给非体育人物强加球队或球衣。

## 设计原则

- 人物被设计系统裁切和重组，允许有意的图像变形；人物可辨认，不能退化为完整大头照加标题。
- 巨字是版式骨架，允许断裂、混合字向、遮挡和半透明穿插；人物仍是核心。
- 第二层素材按项目选择：足球用同一球员有辨识度的高光动作小人物；F1 用对应车队与赛季的赛车，不加独立小车手。辅助图像避开主脸的眼睛、鼻子和嘴，位置与角度随构图变化。其他人物按需求适配，未指定时用主肖像裁片、文字与纸层建立层次。
- 必须有少量、不均匀散落的人物档案与印刷标签。完全排除对阵、赛程、比分、开球时间和赛事预告。
- 配色跟随当前主体的球队、车队、服装或指定色板，集中在几个结构上，不照搬其他球队风格图的颜色。
- 粗粝纸感、撕边、笔触和印刷故障集中于局部，保留密疏差。避免满版统一做旧，也避免过度光洁。
- 新创作延续视觉语言并重组版式；局部修改保留已认可设计。一次作品的修改不变成永久模板。

## 审美标准

“高级”通过清楚的视觉主次、有依据的失衡、统一的字体与配色、局部材质和细节检查实现。保留巨字压图与街头拼贴，不自动转成干净的商业模板。

技能已吸收 `design-taste-frontend` 中适用于平面设计的原则；无需同时安装或调用前端技能。网页的布局、动效与组件规则不套用到海报。生成后检查缩略图的重心与层次，以及放大后的脸、字体、剪贴边缘和辅助素材，不能仅凭提示词保证每张成图质量。

## 安装

将整个仓库目录保存为 `~/.codex/skills/editorial-portrait-poster`，保留根目录的 `SKILL.md` 和 `agents/openai.yaml`。使用自定义 `CODEX_HOME` 时，安装到对应的 `skills/editorial-portrait-poster` 目录。在新会话中调用。

需要可用的图像生成工具；Codex 中使用内置图像生成能力。没有图像工具时只能输出提示词。其他聊天产品不会仅凭 GitHub 链接自动安装 Codex 技能；可将 [SKILL.md](SKILL.md) 中的创作规则或完整提示词提供给支持图片生成的聊天工具使用。

## 使用

```text
$editorial-portrait-poster 为梅西生成一张实验性人物海报，标题 MESSI，使用我给的球衣参考。
```

```text
$editorial-portrait-poster 生成 2026 年兰多·诺里斯的人物海报，核对该赛季号码，采用车队配色。
```

```text
$editorial-portrait-poster 根据我的照片生成地下 zine 人物海报，标题 REKO，不要体育元素。
```

```text
这张构图本身没问题，只是太脏：减轻附加污斑和过密噪点，保留裁切、笔触、文字和色彩。
```

连续创作中可以直接说“换成某某”或给另一张人物图。无参考和尺寸要求时默认一张 2:3 竖图；这不是固定布局。未知姓名的照片可用 `PORTRAIT`，不推断真人身份。可以指定年份、标题、画幅、前景动作与材质强度。

完整规则与可展开的提示词骨架见 [SKILL.md](SKILL.md)。
