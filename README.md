# 实验性人物海报 · Editorial Portrait Poster

一个适用于 Codex 的人物海报技能：巨型脸部特写、小型前景人物、超大文字压图、局部图形失真与纸片撕贴。以排版主导画面，带先锋杂志和地下 zine 气质。

支持任何运动的运动员，也支持音乐人、演员、艺术家、普通人物和虚构角色。可以只给名字、只给人物照片，或同时提供人物和风格参考；不会强制套用足球、球队或球衣设定。

## 安装

将整个仓库目录保存为 `~/.codex/skills/editorial-portrait-poster`，保留根目录的 `SKILL.md` 和 `agents/openai.yaml`。使用自定义 `CODEX_HOME` 时，安装到对应的 `skills/editorial-portrait-poster` 目录。在新会话中调用该技能。

需要可用的图像生成工具；Codex 中默认使用内置图像生成能力。没有图像工具时只能输出提示词。

## 使用

```text
$editorial-portrait-poster 为梅西生成一张实验性人物海报，标题 MESSI。
```

```text
$editorial-portrait-poster 根据这张人物照片生成地下 zine 风格海报，标题 REKO。
```

也可以说“生成一张某人的街头拼贴人物海报”。在同一次连续创作中，直接说“换成某某”或提供另一张人物参考图即可沿用风格；普通人物问答不会触发生成。

默认生成一张 4:5 竖版海报，采用自然彩色人像、真实五官比例、干净肤色与轻量纸感。做旧和扫描效果主要作用于背景、标题与纸边，避开五官；黑白、泛黄和重度复古仅在主动要求时启用。小型前景默认优先不露脸背影或剪影，保留前后层次；需要露脸时优先使用清晰原始照片。可指定标题、强调色、画幅、球队/年代、前景动作和需要保留的服装。没有名字的照片可使用 `PORTRAIT`；没有球队的人物从服装或参考图取色。

完整创作规则见 [SKILL.md](SKILL.md)。
